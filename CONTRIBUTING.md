# Contributing to Obhijatra

Thank you for your interest.

## What you can do now

- **Open an issue** to report a bug, ask a question or suggest an idea. Plain language is fine. Please do not include real personal data in an issue.
- **Report a security problem** privately, following `SECURITY.md`. Do not open a public issue for it.
- **Try the software and tell us what is confusing.** This is very useful at the pre-alpha stage.

## Code contributions

We are **not yet accepting code contributions** (pull requests).

Contributors must sign the FSFE Fiduciary Licence Agreement (FLA) 2.0. The FLA needs a legal entity to receive the rights, and that entity (the registered Aninda Studio) does not exist yet. Code contributions will open once it does, and this file will be updated. See `GOVERNANCE.md` for why.

Pull requests sent before then will be closed politely, with thanks.

## Everyone

All participation is covered by `CODE_OF_CONDUCT.md`.
