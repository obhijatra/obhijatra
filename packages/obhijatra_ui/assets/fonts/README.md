# Bundled fonts

Noto Sans, Noto Sans Bengali, Noto Serif and Noto Serif Bengali, copyright The Noto Project Authors, licensed under the SIL Open Font License 1.1 (see `OFL.txt` in this folder). The licence allows free use, embedding and bundling, including in paid apps, provided this licence file stays with the fonts.

Static unhinted TTF instances, taken from the official Noto repositories on GitHub (https://github.com/notofonts/notosans, notoserif, notosansbengali, notoserifbengali; path `fonts/ttf/unhinted/instance_ttf/`), at these commits:

- notosans: f10dc31fb679345cf9ab0cc4fdca061d03a78b82
- notoserif: 4281f314d93789462225d8a995e2f98def764189
- notosansbengali: 1aff522ed9c79124b96da5025ece7bb791a50e3d
- notoserifbengali: 9035cdb8527bc24af662cc32196d12bd81cf2e67

The files are not modified. Noto Serif Italic is not bundled yet (the Noto repositories ship it only as a variable font); the design system allows italic for quotes only.
